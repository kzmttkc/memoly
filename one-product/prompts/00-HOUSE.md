# One Product — 上位制約

**目的**: Banto と Kabau を**一つの製品として説明できる状態**にする。合併ではない。

## 採用した4点だけ

1. 契約上のサービス名を就業規則AIに揃える
2. SKUを「登録前0円 / 月額 / カスハラ書式19,800」の3つにする（台帳新規は終了）
3. Agent面の主CTAを `/zure` だけにする
4. パック購入メールで Free に招待し、同じ顧客として残す

## 対象外（入れない）

- `/zure` のヒーロー再構築
- ドメインの301
- リポジトリ合併
- Agent面の家（クリーム・明朝・カード群）の全面置換
- ずれ1枚の精度改善（構成を畳む前に測らない）

## 適用順

1. 契約文面（名前が残ると招待メールが割れる）
2. Stripe 商品名と ledger のアーカイブ（Ownerダッシュボード含む）
3. Agent ヒーロー
4. webhook と招待メール

## 完了条件

`CHECKLIST.md`。顧客が契約・領収書・画面のどこを見てもサービス名が就業規則AIで、パック購入の翌日にずれ1枚を残せる。
