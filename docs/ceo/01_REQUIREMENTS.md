## 0. プロダクト定義（1文）

中小の総務・店長が、自社の就業規則ファイルを置くと「書いてあることと書いてないこと」が1枚になり、その後の判断が会社の台帳に残る。手続きSaaSの代替ではなく隣に置く薄い判断レイヤー。

正式名: **就業規則AI**（`lib/brand.ts`）。獲得ドメイン: `banto-roumu.com`（アプリ）＋ `sharoushi-agent.com`（無料ツール・記事・パック）。

## 2. ユーザー要件

### U1. 登録前の価値（Must）

- 利用者は PDF / Word / テキスト貼付で就業規則を置ける（既存 `/zure`）。
- サーバ保存前に「ずれ1枚」が表示される。
- 読めないページは未読として残す（既存仕様維持）。

### U2. 名前を預ける（Must）

- 1枚の保存・継続は登録（メール）でよい。
- クレジットカードは無料開始時に不要。

### U3. 継続課金の理由（Must）

- 会社の前提を覚え、アップロードし直さずに相談できる。
- 出典は自社 / 法令 / 未登録に分かれる（無い行は黙る）。

### U4. カスハラ義務対応（Should〜Must・季節）

- 10措置ギャップとパック書式への導線。
- 施行日は確定情報のみ断定（`lib/legal-facts.ts`）。

### U5. 個人向け無料ツール（Should・獲得）

- 壁シミュ等は個人ジョブを満たし、会社向けCTAは二段化する。
