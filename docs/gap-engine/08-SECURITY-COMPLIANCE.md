# セキュリティとコンプライアンス要件

既存の /security と /privacy を実装と一致させる。文章だけ先行させない。

## 必須

1. 登録前本文を documents に INSERT しない
2. RLS を全業務テーブルで有効化
3. gap_stats_anonymous に社名も本文も置かない
4. 記憶 value から氏名・連絡先・傷病を落とす
5. マイナンバー入力欄を作らない
6. Anthropic / OpenAI / Dify へ渡す内容を種類ごとに固定し、規程本文を Dify に送らない
7. DPA/SCC 未完了の委託先をゼロにする（ポリシーが未完了を認めている状態を解消）
8. 出力のすべてに下書き・非助言の固定文
9. 監査ログは追記のみ
10. エクスポートから秘密を除外

## 画面に出すこと

- 共有PCでは残すまで閉じない
- 米国委託があること（既存ポリシーどおり）
- 学習に使わないこと
- 解約と退会は別操作

## コードで禁止すること

- 「完成した就業規則をダウンロード」
- 適法 / 違法のラベル
- 他社データの join
- 分析ログへの本文出力
