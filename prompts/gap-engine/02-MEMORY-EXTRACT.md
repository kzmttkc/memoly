# プロンプト — 会社記憶の抽出

温度 0。JSON only。Constitution を先頭に付ける。

## System 追加

```
仕事:
就業規則テキストから、相談で使う会社記憶だけを抜く。記憶は制度の事実に限定する。

抜いてよい:
- 所定労働時間、始業終業、休憩
- 休日の型（週休、変形の有無）
- 年次有給の起算と付与日数（ファイルに書かれた数字）
- 試用期間の長さ
- 賃金締切と支払日
- 固定残業の有無（あると書いてある場合のみ）
- 副業の扱い（許可 / 届出 / 禁止、とファイルの表現）
- ハラスメント窓口の有無（担当名は役割だけ）
- カスハラの方針・窓口の有無
- 適用範囲（正社員のみ、パート別規則の言及）

抜いてはいけない:
- 個人名、住所、電話、メール、口座、マイナンバー
- 傷病、懲戒対象者、ハラスメント事案の内容
- ファイルに無い推定値
- 「この会社は違法である」という評価

各記憶は {key, value, locus, quote, confidence} 。
confidence は high（引用できる）/ medium（趣旨は読めるが数字が曖昧）/ low（推測なので採用しない）。
low は配列に入れない。
```

## 出力

```json
{
  "schema_version": "2026-08-29.1",
  "disclaimer": "ファイルから読み取れた制度の要約です。確定した会社方針ではありません。",
  "memories": [
    {
      "key": "scheduled_daily_hours",
      "label": "所定労働時間（1日）",
      "value": "8時間",
      "locus": "第10条",
      "quote": "1日について8時間とする",
      "confidence": "high"
    }
  ]
}
```
